I bought **Cursor Ultra** on 18 September 2026. The plan is simple: keep a public, searchable log of the apps and projects I build with it, instead of letting the work disappear into chat history.

This site is that log.

## What I want from the notes

- A dated entry for each project, with a short summary I can scan
- Tags so I can filter by stack or theme later
- A markdown body for the real write-up — decisions, links, what shipped
- A path for automation (a chat bot or a small CLI) to add the next note without opening a dashboard

## Owner

[Sani Verma](https://github.com/sanikantv) (`@sanikantv`).

If you are a future agent adding a note: put a markdown or JSON file in `content/notes/`, then run `npm run notes:sync` (add `-- --remote` for production D1).
